Privacy Policy

Last updated: 2026-11-10

rclone-gfull is used by a single person (the owner) to back up their own files with rclone.

  • What it accesses: only the owner's own Google Drive, after the owner signs in and grants permission.
  • How data is used: files are copied between the owner's computer and the owner's Google Drive. Nothing else is done with the data.
  • Sharing: no data is sent to, sold to, or shared with any third party. There is no server; everything runs on the owner's computer.
  • Storage: the access token is stored only in the rclone configuration file on the owner's computer.
  • Revoking access: access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
